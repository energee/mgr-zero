# Simplify skill

Pi discovers this project skill automatically from `.agents/skills/`.

Invoke it directly with:

```text
/skill:simplify-local
/skill:simplify-local lib/commands/orders.ts
```

The project prompt template at `.pi/prompts/simplify.md` also provides the
short alias:

```text
/simplify
/simplify lib/commands/orders.ts
```
