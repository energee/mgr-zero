# Dreaming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A post-merge CI job that curates the living agent docs (MEMORY, PROGRESS, ARCHITECTURE, AGENTS.md, agent defs) via a reviewable PR.

**Architecture:** One GitHub Actions workflow reusing `anthropics/claude-code-action@v1` runs after each push to `main` (loop-guarded), follows a committed prompt file, and force-pushes its edits to branch `dreaming/main` as a single long-lived PR. Session digests from the remember plugin are un-gitignored so they feed the dream.

**Tech Stack:** GitHub Actions, `anthropics/claude-code-action@v1` with existing `CLAUDE_CODE_OAUTH_TOKEN` secret, `gh` CLI.

**Spec:** `.agents/superpowers/specs/2026-08-31-dreaming-design.md`

## Global Constraints

- Editable by the dream: `.agents/MEMORY.md`, `.agents/PROGRESS.md`, `.agents/ARCHITECTURE.md`, `AGENTS.md`, `.agents/agents/*.md` — nothing else, ever.
- Loop guard verbatim: `paths-ignore: ['.agents/**.md', 'AGENTS.md', '.remember/**']` and `concurrency: group: dreaming / cancel-in-progress: true`.
- Dream output is always a PR from branch `dreaming/main`; never a direct commit to `main`.
- This repo has no test harness for workflows; each task's check is YAML/structure validation plus `git diff` review. Do not add dependencies.
- Work in worktree `.agents/worktrees/agent-prompting`, branch `agent-prompting`.

### Task 2: Dream prompt — `.agents/agents/dreaming.md`

**Files:**

**Interfaces:**

- [ ] **Step 1: Write the prompt file**

```markdown
# Dreaming — curate the living agent docs

You are running unattended in CI after a merge to main. Your job is memory
consolidation: make the living agent docs match reality, citing evidence.

## Editable files (the ONLY files you may change)
- .agents/MEMORY.md
- .agents/PROGRESS.md
- .agents/ARCHITECTURE.md
- AGENTS.md
- .agents/agents/*.md

## Gather signal
1. Find the last dream: `git log --author="claude" --grep="dream" --format=%H -1 -- .agents/MEMORY.md`
   (empty on the first run — then use the last 25 commits as the window).
2. Review the window: `git log --stat <last-dream>..HEAD` and
   `gh pr list --state merged --limit 20 --json number,title,body,mergedAt`.
3. Read the .remember/*.md session digests.
4. Read every editable file end to end.

## Curate (editable files only)
- Prune facts contradicted by merged work; convert relative dates to absolute.
- Merge duplicate or overlapping entries.
- Resolve contradictions in favor of the newest evidenced fact.
- Record durable decisions evidenced by merged PRs; skip anything speculative.

## Flag, never fix
Drift in read-only artifacts — specs, wireframes, code, workflows — goes in
the PR body as a checklist (e.g. "wireframes out of step with UI plan §4").
Never delete a spec. Never copy secret-shaped strings out of digests.

## Publish
- No changes needed → print "Nothing to dream about" and stop. Do not open a PR.
- Otherwise:
  1. `git checkout -B dreaming/main`
  2. Commit with message starting `dream:` and a body listing each change
     with its evidence (commit SHA or PR number).
  3. `git push -f origin dreaming/main`
  4. `gh pr create --base main --head dreaming/main --title "dream: agent doc maintenance" --body <changes+flags>`
     — if a PR for dreaming/main already exists, `gh pr edit` its body instead.
- Keep the diff small. If everything seems wrong, flag it in an issue-sized
  PR-body note and change only what you can cite.
```

### Task 3: Workflow — `.github/workflows/dreaming.yml`

**Files:**
- Create: `.github/workflows/dreaming.yml`

**Interfaces:**
- Consumes: `.agents/agents/dreaming.md` (Task 2), `CLAUDE_CODE_OAUTH_TOKEN` secret (exists — used by claude.yml).

- [ ] **Step 1: Write the workflow**

```yaml
name: Dreaming

on:
  push:
    branches: [main]
    paths-ignore: ['.agents/**.md', 'AGENTS.md', '.remember/**']
  workflow_dispatch:

concurrency:
  group: dreaming
  cancel-in-progress: true

jobs:
  dream:
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: read
      id-token: write
    steps:
      - name: Checkout repository
        uses: actions/checkout@v6
        with:
          fetch-depth: 0 # the dream reads history since the last dream

      - name: Run dream
        uses: anthropics/claude-code-action@v1
        with:
          claude_code_oauth_token: ${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}
          prompt: 'Read .agents/agents/dreaming.md and follow it exactly.'
          claude_args: '--allowedTools "Read,Glob,Grep,Edit,Write,Bash(git:*),Bash(gh:*)"'
```

- [ ] **Step 2: Validate YAML parses**

```bash
npx --yes js-yaml .github/workflows/dreaming.yml >/dev/null && echo YAML-OK
```

Expected: `YAML-OK`.

- [ ] **Step 3: Commit**

```bash

git commit -m "feat: dreaming workflow — post-merge agent doc curation PR"
```
