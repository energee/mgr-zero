## Order

1 → 2 → 3 (pure, registry) · 4 → 5 (schema, gated) · 6 (loop) · 7 (evals, pure,
any time after 3) · 8 (UI) · 9 (docs).

### Task 1: Registry contract fields

- Modify: `lib/commands/registry.ts`; every `lib/commands/<area>.ts`
- Test: `tests/registry.test.ts` (extend)
- `Def` gains `aiExposed`, `risk`, `preview?`, `compensation`, `idempotency`,
  `offlineReplay`, `atomicity` (spec §2). `listTools({ aiOnly })` filters.
- Failing test first: a write command missing any field throws at
  `defineCommand`; `aiExposed: true` on a write with no `preview` throws;
  `listTools({aiOnly:true})` excludes untagged defs and `preview_command`.
- Tag every current command explicitly; `import_csv`/`invite_*` stay false.
- Commit `feat(ai): registry contract fields + aiExposed filter`.

### Task 2: `preview_command`

- Create: `lib/commands/preview.ts`; modify `lib/commands/all.ts`
- Test: `tests/commands-preview.test.ts`
- Query, roles `any`, not `aiExposed`. Runs `safeParse`, role check, `preview`
  hook; never the handler. Returns canonical, effects, warnings, `allowed`,
  and a version token (hash of the rows the hook read — the hook returns
  `{ effects, warnings, versionOf: rows[] }`).
- Failing test: valid input → `valid:true` + token; invalid → messages, nothing
  written; disallowed role → `allowed:false`; a def without a hook → `preview:null`.
- Commit `feat(ai): preview_command canonical preview + version token`.

### Task 3: Commit revalidation

- Modify: `app/api/command/route.ts` (accept optional `previewToken`),
  `lib/commands/registry.ts` (`runCommand` re-runs the hook and compares)
- Test: `tests/api-command.test.ts` (extend)
- Failing test: stale token → 409 `CommandError`, no write; matching token →
  normal commit; omitted token → unchanged behavior (forms).
- Commit `feat(ai): commit rejects stale preview token`.

### Task 4: Attribution — `SCHEMA-GATE`

- Test: `tests/command-idempotency.test.ts` (extend), `tests/schema-rules.test.ts`

### Task 6: Agent loop

- Create: `lib/chat/agent.ts`, `app/api/chat/route.ts` (streaming; no logic)
- Modify: `package.json` (`@anthropic-ai/sdk`), `.env.example`, README env table
- Test: `tests/chat-agent.test.ts` (stubbed client)
- Loop per spec §4: exposed queries run under `ctx` with capped rows; an
  exposed write halts and returns the candidate; resume after commit. Per-
  brewery rate/cost cap and timeout return a message with `openAsForm`.
- Failing tests: query tool executes and result is fed back; write tool halts
  with candidate and nothing written; `customer` ctx tool list is only
  `portal_*`; `preview_command` absent from tools; cap exceeded → message,
  no model call; missing `ANTHROPIC_API_KEY` → route 503, forms unaffected.
- Commit `feat(ai): agent loop — read freely, halt on write`.
