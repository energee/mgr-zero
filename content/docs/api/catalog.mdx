---
title: "Catalog & pricing"
description: "Brands, formats, SKUs, sale channels, price groups and prices."
---

A brand is the beer's sellable identity — name, style, ABV. A
format is the physical package (keg, can, bottle); it owns `unitsPerCase` and
`bblPerUnit`. A poured format (a pint, a taster) never holds stock: it is a
ratio back to the keg it pours from, and never becomes a SKU. A SKU is one
brand × one packaged format, with an optional UPC.

Prices live on a grid, not on SKUs. A price group is a row of that grid and a
brand sits on one; a sale channel is the column and a customer sits on one.
`set_channel_price` fills one cell — sale channel × price group × format —
with an integer `unitPriceCents`, and every SKU of that group and format sells
at it on that channel. `clear_channel_price` empties the cell, which unprices
those SKUs on that channel. There is no per-SKU exception.

## clear_channel_price [#clear_channel_price]

`command` · admin, sales

Empty one cell of the price grid; SKUs on that group and format become unpriced on that channel

| Field | Type | Required |
| --- | --- | --- |
| `saleChannelId` | uuid | yes |
| `priceGroupId` | uuid | yes |
| `formatId` | uuid | yes |

```bash
curl -X POST "$MGR_URL/api/command" \
  -H 'content-type: application/json' \
  -H "authorization: Bearer $MGR_TOKEN" \
  -d '{ "breweryId": "00000000-0000-0000-0000-000000000000", "name": "clear_channel_price", "requestId": "11111111-1111-1111-1111-111111111111", "input": { "saleChannelId": "00000000-0000-0000-0000-000000000000", "priceGroupId": "00000000-0000-0000-0000-000000000000", "formatId": "00000000-0000-0000-0000-000000000000" } }'
```
