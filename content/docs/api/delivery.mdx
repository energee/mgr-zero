---
title: "Delivery & routes"
description: "Routes, stops, departure, delivery and return."
---

A route groups a driver's shipped orders and picked stock transfers into one
run. It is built, saved, departed, and returned. Each stop is confirmed as
delivered along the way, and `return_route` refuses until every stop on the
route has been confirmed delivered.

{/* ops:delivery */}

## confirm_delivery [#confirm_delivery]

`command` · admin, warehouse

Sign a delivery stop as the assigned driver or an admin; an on-delivery shipment gets its invoice now (shipped quantities, order prices); a transfer stop is only stamped; never moves stock

| Field | Type | Required |
| --- | --- | --- |
| `deliveryId` | uuid | yes |
| `signedBy` | string | yes |

```bash
curl -X POST "$MGR_URL/api/command" \
  -H 'content-type: application/json' \
  -H "authorization: Bearer $MGR_TOKEN" \
  -d '{ "breweryId": "00000000-0000-0000-0000-000000000000", "name": "confirm_delivery", "requestId": "11111111-1111-1111-1111-111111111111", "input": { "deliveryId": "00000000-0000-0000-0000-000000000000", "signedBy": "string" } }'
```
