---
title: "Packaging"
description: "Packaging runs, formats and their bills of material, repacks."
---

A format is a packaging configuration: what a SKU is filled into and what that
consumes. Its bill of material is replaced wholesale rather than patched line by
line, so a partially edited BOM never exists.

A packaging run is scheduled, then closed with what it actually produced and
consumed. Closing is the step that moves beer out of a vessel and finished goods
into inventory. No operation here previews a run's material shortfalls before
scheduling — that read belongs to the Packaging screen, not this reference.

Closing a run requires confirmed material `actuals` and the `planRevision` returned by `get_packaging_close_plan`. Omit them only to replay an already completed pre-upgrade request with its original request ID. Used plus lost quantities debit explicit sources; unused is an observation. The close stores the reviewed BOM and actuals atomically with outputs and tank draw. `correct_packaging_material_record` appends exact material reversals and replacement actuals, without changing finished output or tank volume. Downstream finished-goods use, completed batches and dependent filed reports prevent correction.

## upsert_format [#upsert_format]

`command` · admin, sales

The same use also fixes its bblPerUnit, unitsPerCase and ounces; a rename still saves

| Field | Type | Required |
| --- | --- | --- |
| `name` | string | yes |
| `basis` | packaged or poured | yes |
| `id` | uuid | no |
| `packageType` | keg or can or bottle | no |
| `kegSize` | half_bbl or quarter_bbl or sixth_bbl or fifty_l or thirty_l or twenty_l | no |
| `unitsPerCase` | integer | no |
| `bblPerUnit` | number | no |
| `priceGroupId` | uuid | no |
| `ounces` | number | no |

```bash
curl -X POST "$MGR_URL/api/command" \
  -H 'content-type: application/json' \
  -H "authorization: Bearer $MGR_TOKEN" \
  -d '{ "breweryId": "00000000-0000-0000-0000-000000000000", "name": "upsert_format", "requestId": "11111111-1111-1111-1111-111111111111", "input": { "name": "string", "basis": "packaged" } }'
```
