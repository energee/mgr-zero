title: "Production"
description: "Recipes, batches, brew days, vessels and fermentation."
---

A recipe is versioned: a batch references the version it was brewed to, so a
later recipe change never rewrites the history of beer already made.

The cellar map is the read behind vessel work: what is in each tank, and for how
long. Fermentation readings are appended per open occupancy and are what an
overdue reading notification is measured against.
