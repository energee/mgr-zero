A recipe is versioned: a batch references the version it was brewed to, so a
later recipe change never rewrites the history of beer already made.

`get_recipe` defaults to the latest version. Pass a positive integer `version`
to read an older saved version, including its own ingredients, water additions
and predicted gravity. `versions` lists all available version numbers, newest
first. A missing recipe or version returns `404 not_found`; history has the
same Admin/Brewer and brewery access restrictions as the current recipe.

The cellar map is the read behind vessel work: what is in each tank, and for how
long. Fermentation readings are appended to an open occupancy, a brewed batch,
or both, and are what an overdue reading notification is measured against. A
reading must carry at least one of `tempF`, `gravityPlato` or `ph`; a note
alone is refused with `400 invalid_input`.

`create_recipe_version` checks each ingredient's `timingMinutes` against its
stage, in minutes. Fermentation and dry hop take whole days, so send a multiple
of 1440, up to 120 days or the fermentation schedule's total, whichever is
longer. Boil takes up to `boilMinutes`, or one day when it is unset. Every other
stage takes 0 to 1440. Mash and fermentation `tempF` values, and the whirlpool
and knockout temperatures, take 25 to 212. A value outside these ranges returns
`400 invalid_input` with the field's path.

### Batch completion in-tank acknowledgement

Completion previews name the current barrels in every open tank. When their total reaches max(0.05 bbl, 0.5% of the batch baseline), the preview sets `inTankRequiresConfirmation`. Completion then refuses unless `confirmInTankBbl` equals the previewed `inTankBbl`. The acknowledgement names the beer and tanks being written off as loss. If tank volume changes after review, completion refuses with the new figures; review and confirm again. Below-threshold residue needs no acknowledgement. Existing loss reconciliation and eight-decimal precision remain unchanged. Unknown-outcome retries keep the exact acknowledgement and request; this does not add reopening or undo.
