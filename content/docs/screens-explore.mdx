Find a screen by name, area or surface and open it in the real shell. Taps
inside the screen walk to the next one: a row opens its detail, a verb opens
the sheet it names, the tabs and rail switch areas. The shell follows the
window width, so narrow the window for the phone layout. Every link on this
page opens the selected screen directly. The [screen inventory](/docs/screens)
is the same set as one long, linkable page.
