This page is generated from the screen inventory in code, so it always matches
what the application draws: every frame below is the real component, rendered
here. The `/design` gallery shows the same frames inside the running shell at
phone and desk widths, and is available while a development server runs.

Frames drawn inside QuickBooks, Square or Slack are not MGR screens — they are
what those products show when MGR writes into them, drawn in each product's own
design language.

The customer-facing manuals are the [staff guide](/docs/staff-guide) and the
[wholesale portal guide](/docs/portal-guide).
