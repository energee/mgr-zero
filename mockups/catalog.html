Illustrative controls and anchor links. No working query, save or navigation is demonstrated.

01 / Brand first, not workflow stateWhole linked rows retain style, explicitly labeled ABV and SKU count. No repetitive Open button or invented readiness badge.
02 / Missing is not zeroABV 0.0% remains a known value. Unset style/ABV and zero SKUs remain distinct. Long names and staff aliases wrap.
03 / One page, clear sectionsBrands lead; Formats stays a comparison table; Price groups and Water profiles are supporting navigation. No new route, tab or dashboard.

Proposed layout · fictional data · not a live-page screenshot. System fonts and simplified chrome are conceptual substitutes. Existing search/category/sort semantics and role-guarded creation remain authoritative. Mock format figures demonstrate units; implementation uses existing formatVolume and current query facts. No stock, prices, margins, readiness/compliance rollup, new filter, provider operation or product implementation is proposed.
