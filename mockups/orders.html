All controls illustrative; fictional links are not a working application.

1 · Facts get their own placesOrder, customer, requested date, status, and next action have stable columns. Phone records retain these labels without forcing a table.
2 · Missing is not an alertAn absent requested date reads “Not scheduled.” Long customer names wrap. “transfer” preserves the current missing-customer fallback without inventing a destination.
3 · State is not a commandConfirmed stays visible while Pick or Put back names the valid next step. These admin examples do not grant other roles those verbs.

Proposed layout · fictional data · not a live-page screenshot
System font is a deliberate conceptual substitute, not pixel parity. Existing navigation and status-filter scope are retained; these static controls are illustrative. No amounts, line counts, destinations, overdue claims, or new order states are implied.
